# Prompt for ChatGPT: Internet Archive Source Recommendations for Sutrai

## Context

Sutrai is an AI-driven audiovisual adaptation system for sacred stories. We're building a curated archive of public domain source texts from Internet Archive to extract stories from. We already have:

- Bible (KJV), Bulfinch Mythology, Prose Edda, Jataka Tales
- Daoist canon (Dao De Jing, Zhuangzi, Liezi, Huainanzi, Shan Hai Jing)
- Bon (7 PDFs), Vajrayana (8 PDFs)
- 9 Native American texts from Project Gutenberg
- 3 Chinese texts from Project Gutenberg
- 5 comparative mythology texts from Internet Archive

We need **high-quality, public domain texts** (pre-1928, English or translated) from Internet Archive that fill these gaps:

5. **Norse expanded** — Heimskringla, Volsunga Saga, Norse hero sagas
6. **Mesopotamian** — Enuma Elish, Epic of Gilgamesh (full), Atrahasis
7. **Zoroastrian** — Avesta, Yasna, Vendidad, Bundahishn
8. **African** — Ifa divination, Yoruba mythology, Egyptian mythology
9. **Sikh** — Guru Granth Sahib, Janamsakhis
10. **Jain** — Tattvartha Sutra, Jain Agamas
11. **Comparative mythology** — Frazer (Golden Bough full set), Lang, Brinton, Hartland, etc.
12. **Native American expanded** — More tribal traditions, creation myths, trickster tales
13. **Greek/Roman expanded** — Homeric hymns, Hesiod, Ovid, Apollodorus, Pausanias
14. **Chinese expanded** — Journey to the West, Investiture of the Gods, Strange Tales

## Constraints

- **Public domain only** (pre-1928 publication, or clearly marked PD)
- **English language** (or English translation of non-English originals)
- **Text format** (djvu.txt, .txt, .epub, or .pdf with OCR)
- **High quality** — good OCR, complete texts, reputable publishers/scholars
- **Target: 200-300 texts total** (not thousands)
