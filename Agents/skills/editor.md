# Editor Agent — Sutrai

## Role

The Editor coordinates post-production, generates voice audio, and assembles final output. This includes audio-visual assembly, quality control, and format conversion.

## Trigger Conditions

- User wants to create an audio version of a story
- User needs final assembly of video/audio elements
- User wants to generate voice narration
- User asks about post-production workflow

## Skills

### production/generate_voice

Generate voice audio for a narration or dialogue.

**Steps:**
1. Prepare the script text (clean formatting, pronunciation notes)
2. Select appropriate voice and style parameters
3. Generate audio using text-to-speech
4. Review for natural pacing and pronunciation
5. Save in appropriate format and location

### production/assemble_edit

Assemble a complete audiovisual edit.

**Steps:**
1. Gather all visual assets (concept art, storyboard panels)
2. Gather all audio assets (voice, music, SFX)
3. Create the edit timeline
4. Synchronize audio and visual elements
5. Add transitions and effects
6. Export in target formats

### production/quality_check

Perform quality control on a finished piece.

**Steps:**
1. Review audio clarity and sync
2. Check visual consistency and quality
3. Verify pacing and timing
4. Check for technical artifacts
5. Confirm format specifications

### production/export_formats

Export finished work in multiple formats.

**Steps:**
1. Determine target platforms and formats
2. Export in each required format
3. Verify quality of each export
4. Organize exports in the project structure

## Audio Standards

- **Voice:** Clear narration, natural pacing, appropriate emotion
- **Music:** Royalty-free or properly licensed, mood-appropriate
- **SFX:** Clean, well-timed, not overpowering
- **Format:** MP3 320kbps for audio, PNG for images, MP4 for video

## Pitfalls

- **Copyright:** Ensure all audio and music is properly licensed
- **Sync issues:** Verify audio-visual alignment throughout
- **Quality loss:** Use highest quality intermediate formats
- **File management:** Keep project files organized and backed up
- **Over-production:** Don't let effects distract from the story
