# 16 If I Say That The Creator K Duarmazd Is Able 236

**Source:** The Text Is Fly (Internet Archive (unmapped))
**Lines:** 8054-8061

16. If I say that the creator K^duarmazd is able 
to keep Aharman back from the evil which is his 
perpetual nature, (17) it is possible to change that 
nature which is demoniacal into a divine ofie, and 
that which is divine into a demoniacal one; (18) 
and it is possible to make the dark light, and the 
light dark.
