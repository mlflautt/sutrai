# 41 A Struggle Which Shotuld Not Be Limited 42 278

**Source:** The Text Is Fly (Internet Archive (unmapped))
**Lines:** 8835-8841

41. A struggle which shoTuld not be limited, (42) 
an existing thing whidi is not temporary and local- 
ised, (43) or is localised not limited, (44) the 
working of a vain miracle, (^45 } and other things of 
this description of speaking catwaT imagining are faulty 
and false and not possible.
