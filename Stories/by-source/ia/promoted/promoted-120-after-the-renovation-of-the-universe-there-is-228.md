# 120 After The Renovation Of The Universe There Is 228

**Source:** Sacred Books Of The East (Internet Archive (unmapped))
**Lines:** 6755-6774

120. After the renovation of the universe there is 
no demon, because there is no deceit ; and no fiend, 
because there is no falsity ; there is no evil spirit 
(an gram in 6), because there is no destruction; there 
is no hell, because there is no wickedness ; there is 
no strife, because there is no anger; there is no 
hatred, because there is no ill-temper (dazlh); 
there is no pain, because there is no disease. 

1 2 1. There is also no DahAk®, because there is 
no fear; there is no want, because there is no 
greediness ; thiere is no shame, because tliere is no 
deformity; thtere is no falsehood®, because there 
is no desire of falsehood; there is no heterodoxy, 
because there are no false statements ; and there is 
no tardiness, because it speaks of a dilatory (.yusto) 
race in that which is said thus : ‘ TJicy arc all those 
of evil thoughts, of evil words, of evil deeds, a race 
of all evils to be made to tear by the evil spirit’
