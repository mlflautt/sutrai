# 3 The Seven Efficient Bays Etc Ajijanat Sapta 1898

**Source:** Htst Airp Swirtc (Internet Archive (unmapped))
**Lines:** 15275-15283

3. The Seven Efficient Bays, etc.— Ajijanat sapta 
karun ahna chich-chakrur vayum grinantah is rather obscure : 
it is explained by the Scholiast as in the text. 

4. (Indra). —The Scholiast says Surya, but this can only 
be as identical with Indra , to whom the hymn is addressed. 

Page 110.
