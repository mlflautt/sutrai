# 3 They Have Set Limits Etc Sam Matrabhir Mamire 1768

**Source:** Htst Airp Swirtc (Internet Archive (unmapped))
**Lines:** 13782-13787

3. They have set Limits, etc. —Sam matrabhir mamire, 
is explained, matrabhih rodasyau iyattaya parichchhinne 
chalcruh , with the elements they made determinate divisions 
of heaven ami earth by so much, that is, to a definite limit or 
extent.
