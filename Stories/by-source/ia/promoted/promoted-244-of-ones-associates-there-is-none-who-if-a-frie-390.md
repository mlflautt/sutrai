# 244 Of Ones Associates There Is None Who If A Frie 390

**Source:** The Text Is Fly (Internet Archive (unmapped))
**Lines:** 11020-11025

244. Of ones associates there is none who, if a friend, 
is not one’s enemy, no praiser who is not complain- 
ing of one, no glorifier even who is not scorning one ; 
a character of this description is manifest among all 
creatures.
