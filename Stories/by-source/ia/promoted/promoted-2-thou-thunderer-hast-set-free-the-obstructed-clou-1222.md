# 2 Thou Thunderer Hast Set Free The Obstructed Clou 1222

**Source:** Htst Airp Swirtc (Internet Archive (unmapped))
**Lines:** 9577-9582

2. Thou, thunderer, (hast set free) the obstructed clouds 
in their seasons ; thou hast invigorated the strength of 
the cloud: fierce Indra, destroying the mighty Ahi 
when slumbering (in the waters), tyiou hast established the 
reputation of thy prowess.
