# 5 Do Thou Parjanya Through Whose Function The 1644

**Source:** Htst Airp Swirtc (Internet Archive (unmapped))
**Lines:** 12556-12560

5. Do thou, Parjanya, through whose function the 
earth is bowed down ; through whose function hoofed 
cattle thrive; through whose function plants assume all 
kinds of forms, grant us great felicity.
